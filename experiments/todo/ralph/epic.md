# Current epic

Deliver a **client-side todo application** in this experiment directory using **Vite**, **React 18**, and **TypeScript**.

**Outcome:** Users capture todos quickly, see what matters now, complete or defer work, and recover archived items—all persisted in **localStorage**, with **filters** (All / Active / Completed / Archived) and a **polished** single-page UI.

**Scope:** Features and constraints are defined in `requirements.md` at the root of this experiment. Stay within that document unless this epic is explicitly revised.

**Non-goals for this epic:** Backend, auth, multi-user sync, tags, subtasks/hierarchy, customizable section labels (consider for a later epic).

**Success criteria:** All acceptance criteria in `requirements.md` §6 are satisfied; `npm run dev` and `npm run build` succeed.

Ralph uses this together with `requirements.md` to choose and prioritize tasks.
